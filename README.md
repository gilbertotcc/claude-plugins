# Skills

This repository provides agent skills for tools such as Google’s Gemini CLI,
Anthropic’s Claude Cowork/Code, and Perplexity. Implementations adhere to the
[Agent Skills](https://agentskills.io/) specification to support cross-tool
compatibility, although full compatibility cannot be guaranteed based on
publicly available information.
